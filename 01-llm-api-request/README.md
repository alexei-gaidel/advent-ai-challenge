# 01 — Запрос в LLM через API

**Задание:** написать минимальный код, который отправляет запрос в LLM через API,
получает ответ и выводит его в консоль или простой интерфейс (CLI / Web).

Отправляет запрос в LLM через HTTP API, получает ответ и выводит его — в консоль (CLI)
или в браузер (веб-интерфейс). Зависимостей нет, только стандартная библиотека Python.

## Настройка

Ключ берётся из `.env` в корне репозитория — см. [инструкцию в корневом README](../README.md).

## Запуск — CLI

```bash
cd 01-llm-api-request
python3 main.py "Объясни рекурсию в двух предложениях"   # разовый вопрос
python3 main.py                                          # чат с историей диалога
```

## Запуск — веб-интерфейс

```bash
python3 web.py            # откроется http://localhost:8000
```

## Как это работает

1. Собирается JSON `{"model": "deepseek-chat", "messages": [...]}`.
2. POST на `https://api.deepseek.com/chat/completions`, ключ передаётся
   в заголовке `Authorization: Bearer <ключ>`.
3. Из ответа берётся `choices[0].message.content` и показывается пользователю.

Вся работа с API — в функции `ask()` в `main.py`; `web.py` вызывает ту же функцию,
а браузер общается с ним по локальному эндпоинту `POST /api/chat`.

API DeepSeek совместим с форматом OpenAI, поэтому смена провайдера — это замена
`API_URL` и `MODEL` в начале `main.py`.
