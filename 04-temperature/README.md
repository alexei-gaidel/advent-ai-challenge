# 04 — Температура

**Задание:** выполнить один и тот же запрос с `temperature` 0, 0.7 и 1.2. Сравнить
ответы по точности, креативности и разнообразию. Сформулировать, для каких задач лучше
подходит каждая настройка.

## Запуск

```bash
cd 04-temperature
python3 web.py            # откроется http://localhost:8004
```

Три окна рядом — по одному на температуру. Переключатель сверху меняет задачу
(фактическая или творческая), запрос можно переписать своими словами.

## Как измеряется разнообразие

Ключевой момент: **разброс виден не внутри одного ответа, а между повторами одного и
того же запроса**. Поэтому каждая температура прогоняется по три раза, а разнообразие
считается численно, а не на глаз:

- **сходство повторов** — среднее попарное `difflib.SequenceMatcher` по всем прогонам,
  в процентах. 100% — все прогоны совпали дословно;
- **уникальных слов** — размер общего словаря по всем прогонам температуры;
- **точность** — для фактического вопроса ответ проверяется по эталонным подстрокам
  (`1957`, `Спутник-1`), результат вида «3 из 3».

Две задачи разного склада: у фактической есть один правильный ответ, у творческой
правильного ответа нет.

## Результаты прогона

### Фактический вопрос

> В каком году был запущен первый искусственный спутник Земли и как он назывался?
> Ответь одной строкой.

| temperature | сходство повторов | уникальных слов | точность |
|---|---:|---:|---:|
| 0 | 100% (совпали дословно) | 10 | 3 из 3 |
| 0.7 | 100% (совпали дословно) | 10 | 3 из 3 |
| 1.2 | 76% | 12 | 3 из 3 |

При 0 и 0.7 три прогона выдали одну и ту же строку символ в символ:

> Первый искусственный спутник Земли был запущен 4 октября 1957 года и назывался «Спутник-1».

При 1.2 формулировка поплыла, а факт — нет:

> Первый искусственный спутник Земли — «Спутник-1» — был запущен 4 октября 1957 года.
> Первый искусственный спутник Земли был запущен в 1957 году и назывался «Спутник-1».

Заметная деталь: в двух прогонах из трёх при 1.2 пропала точная дата — осталось только
«в 1957 году». Ответ формально верный, но менее полный.

### Творческая задача

> Придумай название и слоган для маленькой кофейни у метро. Ответь одной строкой
> в формате «Название — слоган».

| temperature | сходство повторов | уникальных слов | результат |
|---|---:|---:|---|
| 0 | 83% | 11 | «У метро» повторилось дословно 2 раза из 3 |
| 0.7 | 91% | 11 | те же «У метро», меняется только хвост слогана |
| 1.2 | 39% | 18 | «Пятый угол», «Чёрный Квадрат», «Угол у метро» — все разные |

При 1.2 модель впервые ушла от буквального «У метро» к образным названиям:

> «Пятый угол» — «Твой кофе между ветками метро».
> «Чёрный Квадрат» — «Кофе без лишнего, зато у самого метро».

## Выводы по трём осям

**Точность.** На простом фактическом вопросе не пострадала нигде: 3 из 3 при всех трёх
температурах. Высокая температура ударила не по правильности, а по полноте — часть
прогонов потеряла дату запуска. То есть 1.2 не превращает факты в вымысел на лёгком
вопросе, но перестаёт гарантировать одинаковую детализацию.

**Креативность.** Разница качественная, а не количественная. При 0 и 0.7 модель выдала
самое очевидное название («У метро» — прямая калька с задания). Оригинальные варианты
появились только при 1.2.

**Разнообразие.** Растёт заметно только к 1.2: сходство повторов упало с 83–91% до 39%,
словарь вырос с 11 слов до 18. Между 0 и 0.7 разницы почти нет — на коротких ответах
0.7 ведёт себя почти как ноль.

## Для каких задач какая настройка

| temperature | Когда использовать |
|---|---|
| **0** | Извлечение данных, классификация, парсинг, перевод терминов, генерация кода, ответы по документам, всё, что уходит в автотесты или в базу. Нужен один и тот же ответ на один и тот же вход. |
| **0.7** | Диалог с пользователем, объяснения, черновики текстов, суммаризация. Формулировки живее, но смысл не уплывает — компромисс по умолчанию для большинства продуктовых задач. |
| **1.2** | Нейминг, слоганы, сюжеты, мозговой штурм, генерация вариантов «набросай десять идей». Уместна там, где нужен именно перебор непохожих вариантов и есть человек, который отберёт удачные. |

## Две оговорки, которые видно по цифрам

1. **`temperature=0` не гарантирует детерминизм.** На творческой задаче три прогона при
   нуле дали сходство 83%, а не 100% — один ответ отличался. Ноль делает ответ *наиболее
   вероятным*, но повторяемость на стороне API не обещана: сказываются пакетная обработка
   запросов и особенности вычислений с плавающей точкой. Если нужна дословная
   воспроизводимость — кешируйте ответ у себя, а не полагайтесь на температуру.
2. **Три повтора — маленькая выборка.** На творческой задаче сходство при 0.7 (91%)
   вышло *выше*, чем при 0 (83%), хотя по теории должно быть наоборот. Это шум выборки,
   а не свойство модели: в интерфейсе число прогонов можно поднять до пяти. Порядок
   величин при 1.2 (39%) от этого не меняется — там эффект уже перекрывает шум.
