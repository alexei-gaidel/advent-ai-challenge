# Advent AI Challenge

Решения заданий челленджа. Одно задание — одна пронумерованная папка со своим `README.md`
и работающим кодом. Общий API-ключ лежит в `.env` в корне и подхватывается всеми заданиями.

## Задания

| [04](04-temperature/) | Температура | Один запрос при temperature 0 / 0.7 / 1.2 в трёх окнах, с замером повторяемости и разнообразия |
| [05](05-model-versions/) | Версии моделей | Один запрос в модели 7B / 27B / 120B через Groq: время, токены, стоимость; качество судит DeepSeek |
| [06](06-agent/) | Первый агент | Веб-чат со split-screen: агент как объект с памятью и настройками, два провайдера, формат данных TOON |

## Настройка (один раз)

```bash
cp .env.example .env      # затем вписать ключи
```

Нужны два ключа: `DEEPSEEK_API_KEY` (platform.deepseek.com) — используется в заданиях
01–04 и как судья в 05, и `GROQ_API_KEY` (console.groq.com/keys) — для задания 05.

`.env` внесён в `.gitignore` и в репозиторий не попадает. Скрипты ищут его
рядом с собой и выше по дереву, поэтому запускать можно из любой папки.

## Запуск

```bash
python3 01-llm-api-request/main.py "Привет"
```

Подробности по каждому заданию — в `README.md` внутри его папки.

## Соглашения

- Папка задания: `NN-короткое-описание` (`02-...`, `03-...` и далее)
- Внутри — `main.py` и `README.md` с условием задания и командой запуска
- Только стандартная библиотека Python, если задание не требует иного
- Секреты — всегда через `.env`, никогда в коде
